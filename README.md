# GlideBlinds Website

A simple, professional website for GlideBlinds - a Canadian custom blinds and shades company.

## 🎯 Features

- **Quote Request Form** - Clients can request free quotes for custom blinds
- **Home Visit Scheduling** - Clients can schedule in-home consultations
- **Multi-Page Website** - Home, About, Blog, and Contact pages
- **Professional Logo Integration** - Uses the GlideBlinds.png logo
- **Yellow-Accent Color Scheme** - Modern blue and yellow color palette
- **Responsive Design** - Works perfectly on all devices
- **Professional Layout** - Clean, modern design with Canadian branding

## 🚀 Deployment

### Option 1: Simple Hosting
1. Upload `index.html` to any web hosting service
2. No build process required
3. Works immediately

### Option 2: GitHub Pages
1. Push to GitHub repository
2. Enable GitHub Pages in repository settings
3. Website will be available at `https://yourusername.github.io/repository-name`

### Option 3: Netlify
1. Drag and drop `index.html` to Netlify
2. Get instant live URL
3. Free hosting with custom domain option

## 📧 Form Integration

The forms currently log to console. To receive actual submissions, integrate with:

- **Formspree** (free tier available)
- **Netlify Forms** (if hosting on Netlify)
- **EmailJS** (client-side email)
- **Your own backend** (PHP, Node.js, etc.)

## 🎨 Customization

- **Colors**: Edit CSS variables in the `<style>` section
- **Content**: Modify HTML directly
- **Forms**: Adjust form fields as needed
- **Branding**: Update company name, contact info, and messaging

## 📱 Mobile Responsive

The website automatically adapts to:
